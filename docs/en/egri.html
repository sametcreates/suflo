How do I use a curve code?
  1. Download Suflo and open it in Premiere (Window › Extensions › Suflo). Free.
  2. In the Easing tab, paste the code into Share and import and press Load. Paste a Speed Ramp code into the code box under Speed Ramp › Custom curve.
  3. The preview plays right away and you can keep the code as a preset. Applying the curve to your own keyframes needs Suflo Pro (or a free trial use).

To share your own curve, in the panel go to Easing › Share and import › Copy code. The code only carries the curve's shape and name; no file paths, projects or personal details.
